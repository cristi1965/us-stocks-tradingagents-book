# 读这个工程，先看哪里？

想系统学习，请先打开 `interactive/index.html`。首页不是文章目录，而是同一条七阶段主线：认清账户 → 收集证据 → 写出可推翻的判断 → 计算风险 → 检查计划 → 模拟执行与复盘 → 选修期权。每阶段只要求完成少量核心课，并明确学完要留下什么、什么情况下才能进入下一阶段。

想先看整体关系，再打开 `interactive/maps.html`：学习路线、领域关系、决策流程、下单时序四张图都带白话说明和相关练习链接。首页和文章页的“先看全貌”可进入。图源保存在 `figures/`，网页使用本地SVG，手机可横向查看或缩小看全图。

进入任意详情后，也会看到三步局部图：前一步 → 当前重点 → 下一步。当前位置会高亮，并可就地展开对应大图；这个局部图已覆盖28课、354道文章练习和118篇文章。

28课是主线，不要求先刷完118篇文章。每阶段列出的文章只在需要更多解释时再读，其余文章保留为可搜索资料库。遇到虚线词，悬停或点击就能查中文解释。

想按问题查资料，请打开 `interactive/library.html`。118篇文章默认显示课程通俗改写，每篇保留核心解释、例子与边界；需要对照时再点“参考原文”。以前的模拟工具仍在 `interactive/legacy.html`，其中的文章按钮也会进入通俗版阅读页。

想把文章学会用，请点文章里的“练这一点”或“把这篇拆开做题”。每篇分成几个独立知识点，在首页的同一个做题模块学习、作答和看错因；也可在首页选择“文章拆解”。这些题和基础28课共用复习清单、笔记与导出记录，原来的进度继续保留。

## 文件分别做什么

| 文件或目录 | 白话说明 |
| --- | --- |
| `interactive/curriculum.js` | 七阶段主线：每阶段包含哪些必学课、补充文章、产出和过关条件 |
| `interactive/learning-content.js` | 现在28课的教学文字、例题和答案 |
| `interactive/learning-glossary.js` | 中英文词典，每个词有意思、例子和误解提示 |
| `interactive/articles-plain-*.json` | 118篇通俗改写正文，每篇有原结构记录与删改说明 |
| `interactive/article-practice-1.json` 至 `article-practice-3.json` | 文章拆出的知识点、情境题、每个选项的解释与来源小标题 |
| `interactive/articles-original.json` | 原文对照；不冒充本项目新写的内容 |
| `archive/pre-full-eli5/` | 改写前的旧文档，供核对历史记录 |
| `interactive/course-*.js` | 旧版课程、对话与模拟工具；多个文件会一起决定最终页面 |
| `manuscript/outline.md` | 全书顺序，说明每节要学什么 |
| `specs/` | 开发约定：准备改什么、怎样判断改好了 |
| `docs/research/` | 以前的调研与问题记录，文中的“当前”指记录日期 |
| `research/primary-sources.md` | 以前查资料时保存的来源，不代表本次已重新核实法规 |
| `reviews/`、`evidence/` | 历史检查记录，不是本次改写自动获得的认证 |
| `verify-*.cjs` | 自动检查脚本，证明某些操作能用，不能证明一定学会 |

## 文档里的英文在说什么

Paper / Paper-only 是模拟交易，不是真的拿账户资金买卖。all-in 指把几乎所有可用资金押上。仓位是已经买卖的数量或金额；暴露是某个价格、行业或利率变化会让你承担多少影响。

ELI5 在这里指把事情讲得像第一次接触也能懂：先用普通话讲清，再给专业名字；不是删掉必要条件，也不是把风险讲成保证。

| 写法 | 怎么理解 |
| --- | --- |
| spec / plan / tasks | 修改要求 / 实施顺序 / 待做清单 |
| P0 / P1 / P2 | 最先修 / 接着修 / 后续改进；不是收益或学习成绩 |
| gate / fail-closed | 先检查条件；缺少条件就不放行 |
| evidence / receipt | 留下的依据 / 一次操作返回的记录；模拟记录不是真实成交证明 |
| TTL / as-of / available-at | 最长允许多旧 / 数据对应哪个时刻 / 最早何时能看到 |
| actual / consensus / prior | 公布值 / 事前预期 / 上一期数值；比较前要确认是同一种指标 |
| point-in-time / vintage | 只用当时知道的信息 / 当时发布的那个版本 |
| settled cash / house requirement | 已完成结算的可用资金 / 券商自己规定的资金要求 |
| TIF / DAY / IOC / GTC | 订单有效时间 / 当日有效 / 立即成交能成交部分并撤掉余单 / 撤销前有效但具体期限看券商 |
| locate / SSR | 卖空前核查能否借到股票 / 对部分卖空报价的限制；适用条件查对应规则 |
| OHLCV / RVOL | 开高低收和成交量 / 当前成交量与历史可比量的比值 |
| Greeks / IV Crush | 期权价格对不同条件的变化有多敏感 / 市场给波动定价下降 |
| implementation shortfall | 实际执行比原计划多花或少得到多少，还可能包括没成交的代价 |
| reconciliation | 把订单、成交和持仓逐项对起来，看是否有漏记或重复 |
| regression / smoke test | 检查旧功能有没有被改坏 / 先检查页面能打开、关键步骤能走通 |

文档中的API字段、代码和引用标题保留原文，便于查找。看到“已通过”时还要看日期、范围和测试内容，不能据此推断整个系统或金融结论都已验证。
