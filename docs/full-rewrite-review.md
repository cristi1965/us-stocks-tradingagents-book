# 通俗改写的独立审读记录

两位独立审读者检查了本轮长文和实际阅读页。第一位读第二批40篇，第二位读第一批40篇和第三批38篇；写作者各自已阅读对应原文。审读者不是合格金融专业人员，本记录不作为专业认证，也不保证原文所有细节都逐项保留。

## 第一轮：正文与阅读器

40篇未发现明显算术或核心概念错误。实际用Chrome抽查MACD、订单和三张财报，桌面及390px阅读、术语打开/Escape、原文对照可用。

发现并修复：

- 小标题跳到h3且字号偏小：正文从h2开始。
- 原文加载完成会覆盖后来选择的通俗版：增加视图请求序号，以最后一次选择为准。
- 原文图表配置直接堆在正文：显示图注，数据折叠并注明此处不绘图，原始数据完整保留。
- 股东权益被误链到个人账户权益：将Account Equity的中文匹配限定为“账户权益”。

前三项经第一位浏览器复核闭合；最后一项由第二位源码复核，主线程浏览器断言通过。

## 第二轮：独立阅读及手机抽查

78篇未发现明显算术错误或整篇通用模板替代内容。抽查390×844页面，正文和词典可读、关闭按钮可用。第二位没有阅读第一位审读报告；后续仅收到具体修复通知以免重复窗口操作。

发现并修复：

- 编校历史打断正文：14处改为直接讲知识，删改说明仍在coverageNote。
- 林奇篇缺研究能力与基金规模的区别：补充两句，说明持仓多不等于研究充分。
- 搜索提示举例Call却无结果：期权首次出现时补全认购（Call）/认沽（Put），两种搜索均有回归断言。
- 单独买入的期权头寸误链两腿组合：删除过宽别名，新增防误链断言。

第二位已源码复核闭合；主线程在最终版本运行verify-library.cjs及verify-terms.cjs通过。
