# 文章拆解与做题融合

118篇文章拆成354道题，另保留28课原有练习。每题独立保存记录，和原来的错题使用同一复习清单。

## 怎么使用

- 阅读页顶部进入本篇练习；对应小标题下直接练这一点；文末列出知识点入口。
- 首页选择“文章拆解”，可搜索题目与知识点；每题先有短解释，再换场景判断或计算。
- 答错后显示具体原因并加入复习；重新答对移出待复习列表。原有进度与笔记不清空。
- 每题可返回原文章；需要查专业词时仍可悬停或点击。
