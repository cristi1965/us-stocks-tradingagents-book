# 本轮重点概念抽查

全量文字改写不是对所有现实规则作新的专业认证。对于最容易被简化错的概念，本轮另外查阅以下一手说明：

- [Investor.gov：订单类型](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders)：核对限价的方向、止损触发后转为市价单、最近成交价不代表自己的执行价。
- [Options Industry Council：期权Greeks](https://www.optionseducation.org/advancedconcepts/understanding-options-greeks)：核对这些数值是理论近似，不能保证权利金准确按它们变化。
- [Investor.gov：T+1结算](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/new-t1-settlement-cycle-what-investors-need-know-investor-bulletin)：区分成交日和随后完成交收的营业日，不把交收期限与账户可取资金、证券能否当日回转混成一个概念。

查阅用于抽查上述文字边界；其他市场的当日规则、券商资格、收费和产品套餐仍需使用时核对。改写中不保留未经重新确认的“2026固定费率”“未来确定政策”或历史胜率承诺。
