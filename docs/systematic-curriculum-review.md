# 七阶段课程重构验收

## 现在怎样学习

首次打开首页先看到七阶段主线，不再要求用户先在“28课、118篇文章、354道题”之间选一种内容载体。

1. 认清自己与账户。
2. 把看到的信息变成证据。
3. 提出可被推翻的判断。
4. 算清能承担多少。
5. 检查整份计划。
6. 模拟执行并复盘。
7. 选修期权。

每阶段都有一个要解决的问题、必学课程、按需精读、实际产出和进入下一阶段的条件。28节核心课全部且只出现一次。118篇文章是资料库，其中少量文章按阶段推荐；354道文章题用于查漏补缺，不作为必须刷完的主线。

课程详情里的局部图也使用同一阶段定义。核心课和推荐文章显示所在主线阶段；其他文章明确标记为补充资料。课程的上一节、下一节以及左侧目录全部改用七阶段顺序。

## 验证记录

- 七阶段、28节唯一归属、推荐文章有效性、阶段目录和连续学习顺序通过自动检查。
- 28节答题、错题复习、笔记、本地保存、搜索、导出和手机宽度通过回归检查。
- 118篇文章和354道题全部渲染，三种选项反馈、来源小标题、加载失败重试通过检查。
- 四张总图、本地图片、详情局部图、桌面与手机布局通过浏览器检查。
- 中英术语的悬停、点击固定、词典搜索、键盘关闭和手机边界通过检查。

“练习通过”只表示这道题曾答对，不代表已经具备真实交易能力；阶段产出和通过条件仍需要学习者自己完成并检查。
