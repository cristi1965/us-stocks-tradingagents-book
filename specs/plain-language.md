# 通俗文字重写

目标：第一次接触股票与期权的人，也能按句子顺序读懂，而不需要自己补术语前提。

## 写法
- 标题用读者真正会问的问题。
- 先说发生了什么，再解释为什么，最后再给专业名字。
- 一句话只讲一件事。保留数字、单位和适用条件。
- 不用新的难词解释旧的难词。必须用的词，当句解释。
- 不把“近似”“可能”“题设”改成保证；不把教学假设写成真实行情。
- 用同一场景连接对话、例题和自检，练习明确说明变化。

## 范围与步骤
1. 全面改写28课标题、目标、对话、例题说明和错因，保持题目数值与答案兼容。
2. 改写63条词典的定义、例子、误解提示，保留中英文查询。
3. 页面提示改成直接、自然的说法。
4. 复查首课、期权、组合风险、最后综合题；运行现有浏览器回归。
