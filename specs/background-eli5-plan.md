# 背景讲解怎么写才容易懂

不要假设读者已经懂股票。每节先回答一个具体问题，再解释专业词。

## 一节只走这几步
1. 说清发生了什么：谁买、谁卖、花多少钱。
2. 解释为什么会有这个结果；需要术语时立即给中文意思。
3. 沿用同一个例子，一步步列出数字与单位。
4. 指出这个例子不能保证什么。
5. 换一个条件让读者自己试，答错后指出是哪一步出了问题。

## 写完怎么检查
- 28课都能独立看懂，不用故事和比喻代替关键原因。
- 开盘、最高、最低、收盘要使用同一组数据。图表不能和文字打架。
- 通胀数据要说清比较哪个月份、是否调整过；会议预测不是承诺。
- 市价单优先争取成交，限价单限制价格，二者都不能让市场凭空提供对手方。
- 期权要先讲权利与成本，再算价格变化；近似公式不能当保证。
- AI提供的资料要核对来源和时间，多次重复不等于多份独立证据。
- 手机能读完，键盘能操作，解释在练习前可见。
